# Project Otis

Project Otis is a Github Organization with the goal of designing a 
cross-platform and AI accomodated ecosystem for users of all devices. Whether 
you have an iPhone, and Windows Desktop, or even in the process of going 
open-source with Linux, the goal of this ecosystem is to bridge gaps between
devices while giving an assistant to simplify these services.

The Ecosystem is built around a self-hostable backend program that uses your 
device. Each feature available is built into this central service, but the
programs you wish to use are to your choice. Each service is composed of its
implementation in the backend, a client that integrates the service, and an
MCP server to communicate with the services with an LLM of your choice.

### Compatibility

The ecosystem is heavily in development, but we can confirm compatibility 
with the following operating systems so far:
- Windows
- Android (via Expo Go, will need to test properly in near future

## Features

The goal of this ecosystem is to be composed of everything needed to implement
a Desktop Environment (and potentially a custom OS/Linux Distribution) designed
for the every day user. Some of these features include:
- Device Start/Home Menu with LLM Interface

### In Development Features

These are all the features the project wants to or is in the progress of 
developing:
- AI-Based Desktop File Workspace
- AI-assisted Messaging
